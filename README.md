# Sugy Choi Academic Website

This is a simple static academic website designed for GitHub Pages.

## Publish it on GitHub Pages

1. Create a GitHub repository named:

   `YOURUSERNAME.github.io`

2. Upload all files from this folder to the **root** of that repository.

3. In GitHub, go to:

   **Settings → Pages**

4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

5. Save. Your website should appear at:

   `https://YOURUSERNAME.github.io`

## Before publishing

Update these items in `index.html`:

- Current title / institutional affiliation
- Preferred academic email
- Google Scholar
- ORCID
- LinkedIn / Bluesky / GitHub
- Full bio
- Teaching information

Update `publications.html` with full citations and links.

Add your CV PDF to the root folder and name it:

`Sugy_Choi_CV.pdf`

## Custom domain

You can later buy a domain such as `sugychoi.com` and point it to GitHub Pages without changing the site design.

## Editing

For simple changes, you can edit files directly in GitHub's browser interface. Once committed to the `main` branch, GitHub Pages will republish automatically.
